# Shows

- The layout you had is now a show named Default Show. You can rename it.
- Rename and Delete act on the show on screen. To rename or delete another show, switch to it first.
- From this version on, changes during a show are kept only if you Save that show or use Save As to make a new one.
- A dot after the show name in the header means the layout on screen has changes that aren't saved.
- Quitting puts the saved show back next time.
- Switching to another show, or importing one, asks whether to save your changes first.
- Revert to Saved puts the show back as you last saved it, dropping changes made since. It is available only while you have unsaved changes (the dot in the header).
- If the real show is still in an old hotkey or holding-tank file, load it onto the tabs (Load Tab from File… in the tab's ⋯ menu) and then Save or Save As.
- Save Tab to File… and Load Tab from File… in each tab's ⋯ menu (or right-click the tab) keep one tab as a file you can load into any show, like a pre-show playlist or a standard set of drops. Loading into a tab that has songs asks first. The files are the same `.mrv` and `.hld` files older versions use.
- Shows → Color gives the current show an accent color (Teal, Blue, Purple, Pink, Coral, Amber or Green), shown as a bold color behind the panels, under the active tab and around the show name, so you can see which show is loaded at a glance. It is saved right away. Save As and Import Show keep the color; None takes it off.
- Other people's saved shows can be copied with Shows → Import Show from Another Profile.
- A ▶ count now appears next to every track you've played tonight, in the hotkeys, the holding tank and search results, so you can see what's been played without removing it. Right-click a song and choose Mark as Unplayed to clear one, or use Songs → Mark All Songs as Unplayed to clear them all. Counts start fresh each time the profile opens and come back after a crash restore.
- Profile backups made before this version have no shows. Restoring one turns its layout into a show named Default Show. That layout may be a mid-show backup rather than a prepared show.
- The folder and save icons are gone. Use Save and Save As to keep a show, and Import Show for another person on this computer. Hotkey and holding-tank files load and save from each tab's ⋯ menu.
