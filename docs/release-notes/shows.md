# Shows

- The layout you had is now a show named Show. You can rename it.
- Rename and Delete act on the show on screen. To rename or delete another show, switch to it first.
- From this version on, changes during a show are kept only if you Save that show or use Save As to make a new one.
- A dot after the show name in the header means the layout on screen has changes that aren't saved.
- Quitting puts the saved show back next time.
- Switching to another show, or importing one, asks whether to save your changes first.
- Revert to the saved show puts the show back as you last saved it, dropping changes made since.
- If the real show is still in an old hotkey or holding-tank file, import it onto the tabs and then Save or Save As.
- Other people's saved shows can be copied with Import Show.
- Profile backups made before this version have no shows. Restoring one turns its layout into a show named Show. That layout may be a mid-show backup rather than a prepared show.
- The folder and save icons are gone. Use Save and Save As to keep a show, and Import Show for another person on this computer. Importing hotkey and holding-tank files you already have still works.
