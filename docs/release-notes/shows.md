# Boards

- The layout you had is now a board named Board. You can rename it.
- From this version on, changes during a show are kept only if you Update that board or create a New Board.
- Quitting puts the saved board back next time.
- Revert to the saved board puts the board back as you last saved it, dropping changes made since.
- If the real show is still in an old hotkey or holding-tank file, import it onto the tabs and then Update or create a New Board.
- Other people's saved boards can be copied with Import Board.
- Profile backups made before this version have no boards. Restoring one turns its layout into a board named Board. That layout may be a mid-show backup rather than a prepared show.
- The folder and save icons are gone. Use Update and New Board to keep a show, and Import Board for another person on this computer. Importing hotkey and holding-tank files you already have still works.
